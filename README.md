# simid-measles-waning
Measles transmission model accounting for waning in vaccine-induced immunity.

This repository contains the code used in the following study:

*Impact of changes in measles vaccination schedule under potential waning immunity: policy implications from a modelling study in Flanders, Belgium*

Authors: Laura Di Domenico, Marie-Cécile Dupas, Julie Schenk, Laura Cornelissen, Naïma Hammami, Heidi Theeten, Steven Abrams, Niel Hens
